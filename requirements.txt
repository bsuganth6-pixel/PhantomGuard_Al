# Standard library covers the rest deliberately (difflib for fuzzy brand

# why that's a design choice, not an oversight.

# System dependency (not pip-installable): Tesseract OCR binary
#   Ubuntu/Debian: sudo apt install tesseract-ocr tesseract-ocr-tam
#   (tesseract-ocr-tam enables Tamil OCR -- this dev sandbox only had
#    tesseract-ocr-eng available, see core/ocr_service.py)
#
# NOTE on Vercel: Vercel's Python runtime has no apt/system-package step,
# so this binary can't be installed there -- pytesseract calls will fail
# and the /scan/screenshot route degrades to "OCR failed: ..." instead of
# extracting text (core/ocr_service.py already catches this; it won't
# crash the app, the screenshot-OCR feature just won't work on Vercel).
# The Dockerfile in this repo (which does `apt install tesseract-ocr
# tesseract-ocr-tam`) is the deployment target where OCR, Tamil included,
# actually works -- e.g. Render/Railway/Fly/a VM, or Vercel only if you
# swap this route for an external OCR API.
#
# gunicorn is only used by the Dockerfile's CMD for that deployment path;
# Vercel supplies its own WSGI entrypoint (see index.py) and ignores it.
